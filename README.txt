Cara menjalankan di VS Code + Laragon:
1. Extract ZIP ini.
2. Letakkan folder booking_salon di C:/laragon/www/
3. Buka Laragon dan Start Apache.
4. Buka http://localhost/booking_salon/
5. Kalau mau mengubah gambar, ganti file di booking_salon/assets/images/.
   Nama file yang dipakai:
   - hair_left2.jpg
   - hair_center2.jpg
   - hair_right2.jpg
   - hair_close2.jpg
   - products.jpg
